# Launcher icon provenance

The launcher icon is original project artwork: a centered shield and one thin, compact pair of softly curved, wide-angle DNS signal lines. The adaptive foreground and monochrome layers are maintained as Android vectors; `scripts/generate_launcher_assets.py` generates those vectors, legacy density PNGs, and the 512 px store icon from the same geometry.

The blue (`#0055FF`) and green (`#008000`) are references to colors visible on the official [NextDNS website](https://nextdns.io/). The project does not reuse the NextDNS logo or imply an official partnership. The app remains an independent, unofficial client.
